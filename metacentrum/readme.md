# Metacentrum README

## Overview
This folder contains all the scripts and data needed for training on Metacentrum. It is organized into the following components:

- **Data**: Contains cropped data divided into "Deepfake" and "Original" folders.
- **Model**: Contains the trained model saved during successful training.
- **Proj.py**: This file contains code with the definition of the neural architecture and data loader. It is used to set up the training process.
- **Skript.sh**: This script sets up everything needed for training, including allocating resources, setting the walltime, and specifying the number of CPUs.

For more detailed informations, refer to the comments within the scripts or check the Metacentrum documentation.
