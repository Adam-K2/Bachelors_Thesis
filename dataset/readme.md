# Dataset README

## Overview
This folder contains the dataset that we used in this thesis.  
The dataset for experiments of neural networks was created by gathering images from the LFW and CelebA HQ datasets.
The dataset for experiments for resiliance of facial recognition algorithms against deepfakes was created by gathering images from the CFP FP dataset.

## Dataset Creation Process
- We collected 700 images from the LFW dataset and 700 images from the CelebA HQ dataset.
- For each set of 50 images from the "Original" folder, we used faces from the "Vzor" folder to create composite images.
- The resulting dataset is organized into several folders, each containing images generated by different deepfake programs. 
- The first 700 images in all folders are from LFW dataset, others are from CelebA HQ dataset.
- The test dataset for experiments of facial recognition had collection of 200 people images. We used two images for each person and than for second image generated also deepfake image. 

## Folder Structure
- **Deepfake1**: Output from the deepfake program "Roop."
- **Deepfake2**: Output from the deepfake program "FaceFusion."
- **Deepfake3**: Output from the deepfake program "Ghost," which exclusively uses images from the LFW dataset.
- **Deepfake4**: Output from the deepfake program "SimSwap."
- **face_rec_dataset**: Test dataset for facial recognition experiments
- **Original**: Contains files from the LFW and CelebA HQ datasets.
- **test_data**: Images for evaluation of each model in thesis.
- **Vzor**: Contains faces used to map onto other people.
